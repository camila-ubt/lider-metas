# Líder Metas

Aplicação web de uso interno para acompanhamento das vendas, metas e desempenho das lojas.

O sistema centraliza os lançamentos diários, o controle de metas e o PA das vendedoras, facilitando a conferência dos resultados e o acompanhamento mensal.

Desenvolvido com **Next.js, React e Supabase**.

A documentação detalhada está disponível na [Wiki do Líder Metas](https://github.com/camila-ubt/lider-metas/wiki).
