# Glossário

| Termo | Significado |
|---|---|
| Meta | objetivo base mensal, correspondente a 100% |
| Supermeta | nível de 110% da Meta |
| Megameta | nível de 120% da Meta |
| Slot | combinação de data, loja e período |
| Período | faixa operacional do dia, como manhã ou noite |
| Pendente | slot esperado sem lançamento |
| Parcial | dia ou período com apenas parte dos slots registrados |
| Completo | todos os slots esperados foram registrados |
| Realizado | soma das vendas lançadas |
| Projeção | estimativa de fechamento baseada no ritmo observado |
| Dia de corte | último dia considerado em uma análise |
| Oportunidade restante | dia/período que ainda pode contribuir para o resultado |
| Prévia | relatório parcial, sujeito a mudanças ou pendências |
| Fechamento | consolidação do mês encerrado e conferido |
| RLS | Row Level Security; políticas de acesso aplicadas no banco |
| Chave publishable | chave pública de baixo privilégio usada pelo cliente |
| Chave secreta | credencial elevada, exclusiva de ambientes confiáveis |
| Ruleset | conjunto de regras de proteção da branch no GitHub |
| Pull Request | proposta revisável de alteração antes do merge |
